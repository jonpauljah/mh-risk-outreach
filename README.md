# mh-risk-outreach
This project develops a prototype mental health outreach decision-support system that uses ETL and SQL to process member data, apply rule-based risk scoring, prioritize higher-risk patients, recommend outreach actions, and record short-term outreach outcomes.

See [getting started](getting-started.md) for setup and commands, and
[documentation index](docs/README.md) for architecture and milestone 1 guides.
